PERGUNTAS FREQUENTES

Algumas respostas antes de começar.

O PACT é uma agência?

Não. O PACT é um método de estruturação de negócios. Dependendo do diagnóstico, o projeto pode envolver diferentes estratégias, ativos, processos e tecnologias.

Preciso contratar os quatro pilares?

Não. Os quatro pilares são analisados, mas a execução acontece por prioridade.

Vocês realmente implementam?

Sim, quando existe aderência entre o problema identificado e nossa capacidade de execução, podemos construir um Projeto PACT para a empresa.

O diagnóstico é gratuito?

Sim. Ele funciona como o primeiro passo para entender a estrutura atual do negócio.

Fazer o diagnóstico me obriga a contratar?

Não. O diagnóstico não gera obrigação de contratação.
